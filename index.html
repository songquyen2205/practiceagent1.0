⚙️ Quy Trình Thực Thi End-to-End Qua Team Agent

Bước 1 • BA Agent

BA Lên Ý Tưởng & Đặc Tả

  • Ý tưởng bài toán: Thầy cô lớn tuổi khó nhớ hết công việc từng bạn; mỗi lần gặp lại phải hỏi lại từ đầu.
  • Mục tiêu: App di động lưu bút hoài niệm để từng bạn tự cập nhật hành trình học vấn & công việc khi đổi việc.
  • Chức năng: Danh bạ 24 bạn CT1619, Timeline sự nghiệp, Bảng tin họp lớp & thăm thầy cô 20/11.
  • Đầu ra: Lập tài liệu đặc tả SRS.md chuẩn ISO 29148.
Bước 2 • Tech Lead Agent

Dev Lên Kiến Trúc

  • Kiến trúc Không Backend: Lưu trữ 100% cục bộ bằng AsyncStorage in-app, bảo mật riêng tư tuyệt đối cho lớp học, không tốn chi phí server.
  • Cơ chế Backup/Sync: Cho phép Xuất/Nhập dữ liệu qua file JSON để gửi qua Zalo/AirDrop.
  • Data Model: Chuẩn hoá TypeScript (Member, Milestone, ClassEvent).
  • Đầu ra: Ban hành quyết định tại DECISIONS.md.
Bước 3 • Mobile Dev Agent

Dev Code Sản Phẩm

  • Công nghệ: React Native Expo, TypeScript 100%. Nâng cấp SDK 58.0.0 mới nhất.
  • UI Nostalgic Fresh: Phong cách giấy vintage kraft ấm áp, thẻ kẹp polaroid, washi tape.
  • Phát triển 4 màn hình: Danh bạ lưu bút, Hành trình của tôi, Form cập nhật khi đổi việc, Bảng tin sự kiện.
  • Dữ liệu CT1619: Tích hợp đủ 24 bạn (Song Quyên: Lớp trưởng & BA tại Egitech).
Bước 4 • QC & DevOps Agent

Test & Đóng Gói

  • Kiểm thử Logic: Biên dịch tsc --noEmit đạt 100% không lỗi kiểu dữ liệu.
  • Kiểm thử UI/UX: Mô phỏng kích thước màn hình iPhone thực tế (viewport 412x892), kiểm tra vuốt chạm mượt mà.
  • Chụp ảnh UI: Tự động capture bộ ảnh thực tế 4 màn hình chính của Mobile App.
  • Đóng gói: Push lên GitHub repo độc lập và tự động deploy website showcase.
