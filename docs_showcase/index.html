⚙️ Quy Trình Thực Thi End-to-End (BA Agent Harness v3.0)

1. Khởi Tạo & As-Is / To-Be

  • Bối cảnh: Thầy cô lớn tuổi khó nhớ hết công việc từng bạn; họp lớp phải hỏi lại.
  • Yêu cầu: App mobile lưu bút ghi nhận hành trình học ĐH nào, làm cty nào, đổi việc thì cập nhật.
  • Baseline: Lập hồ sơ SRS.md và quyết định kiến trúc DECISIONS.md.

2. Thiết Kế Kiến Trúc & Data

  • Không BE: Lưu trữ 100% bằng AsyncStorage local in-app, bảo mật riêng tư cho lớp.
  • Data Model: Quản lý Member, TimelineMilestone (học vấn & sự nghiệp), ClassEvent.
  • Sync JSON: Xuất/nhập gói dữ liệu để lớp chia sẻ qua Zalo/AirDrop.

3. Lập Trình React Native Mobile

  • Tech Stack: React Native Expo, TypeScript 100%.
  • Style: Nostalgic Fresh (màu giấy vintage kraft ấm áp, thẻ kẹp washi tape, polaroid).
  • Nâng cấp SDK 58: Tương thích hoàn toàn với Expo Go phiên bản mới nhất trên iOS/Android.
